# SparkTune en diez líneas
1. Sirve a quien quiere preparar un PC para estudiar, crear o programar.
2. El usuario elige un perfil o describe su objetivo.
3. El CLI propone herramientas y explica cómo influye el hardware.
4. Los planes se consultan en Windows, Linux y macOS.
5. Windows puede instalar aplicaciones seleccionadas tras verificar un punto de restauración.
6. Cada cambio de sistema lleva confirmación individual.
7. Un catálogo JSON define las acciones de archivos y sus combinaciones.
8. La simulación muestra los resultados previstos y conserva los originales.
9. La IA ayuda a elegir y explicar, y los perfiles también funcionan sin red.
10. La licencia y la cuenta de los productos comerciales corresponden al usuario.
